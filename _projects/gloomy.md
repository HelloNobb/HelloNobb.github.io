#### 구현

- 임시 파일에 먼저 쓰고 교체하는 원자적 저장과 백그라운드 전환 시 저장을 도입해, 5곳에 흩어진 저장을 파일 1개로 통일하고 강제 종료·파일 손상에 대비
- 싱글톤 직접 호출 70회로 참조가 뒤엉킨 구버전 구조를 단방향 레이어와 이벤트 구조로 재설계하고, 붕괴 원인을 규칙 파일로 명문화해 AI 구현에도 동일하게 적용
- 9개 파일에 흩어진 시간 처리를 게임 시계 하나로 통합해, 배속·시간 점프로 하루 경과 테스트를 24시간 대기에서 버튼 1회로 단축
- 구버전 Android APK 빌드(씬 15개) 후, AI 활용 빠른 회색박스 프로토타입 구현으로 재미 먼저 검증

#### 성과

- 자체 대사 툴('Scriber')의 JSON을 Unity 대화 엔진이 실행하는 제작 파이프라인 구축하여, 대사 수정 시 코드 수정 32개 → 0개
